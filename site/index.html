What your agent does

The skills are a procedure, not a template. Your agent follows it from the brief to a verified handover.

  1. Turns your idea into checksWrites what has to work, so "done" means something you can see.
  2. Picks only what the app needsA database, wallet, mini app host or game loop, only when the idea calls for it.
  3. Builds it in working slicesOn a pinned Next.js starter, mobile first, with real data and real states.
  4. Tests it like a person wouldProduction build plus browser tests on phone and desktop, repairing what fails.
  5. Hands over the evidenceSource, exact commands, test results, and anything still waiting on you.

Install it locally

Your agent downloads the pack by itself when it needs the starter and scripts. To keep a copy, or to install it as a skill:

viniapp-skills.zip viniapp-skills.skill SHA256SUMS 
# Codex: install, then use $viniapp-skills
unzip viniapp-skills.zip -d ~/.codex/skills/

# Or start a project yourself
node viniapp-skills/scripts/create.mjs ./my-app

Needs Node.js 22.11 or newer. Browser tests use Playwright.
